# Route53 + ALB Lab

## Objective

The goal of this lab is to understand how Amazon Route53 integrates with an Application Load Balancer (ALB) and how DNS records can be used to route traffic to AWS resources.

---

```text
User
  │
  ▼

  ▼
Route53 Hosted Zone
  │
  ▼
Alias Record
  │
  ▼
Application Load Balancer
  │
  ▼
EC2 Instances
```

## Step 1: Open Route53

Navigated to:

```text
AWS Console
→ Route53
```

Route53 is AWS's managed DNS service used for domain registration, DNS management, and traffic routing.

---

## Step 2: Create a Hosted Zone

Created a Public Hosted Zone.

Example:

```text
example.com
```

A Hosted Zone acts as a container for DNS records associated with a domain.

---

## Step 3: Review Automatically Created Records

After creating the Hosted Zone, AWS automatically generated:

### NS Record

Name Server records specify which DNS servers are authoritative for the domain.

Example:

```text
ns-xxx.awsdns.com
ns-xxx.awsdns.net
ns-xxx.awsdns.org
ns-xxx.awsdns.co.uk
```

### SOA Record

The Start of Authority (SOA) record contains administrative information about the domain.

These records are automatically managed by AWS.

---

## Step 4: Create an Alias Record

Created a new DNS record.

Configuration:

```text
Record Type: A

Alias: Yes

Target:
Application Load Balancer
```

The Alias Record maps a domain name to an AWS resource.

---

## Route53 to ALB Mapping

Example:

```text
app.example.com
        │
        ▼
my-alb-123456.ap-south-1.elb.amazonaws.com
```

Instead of remembering the ALB DNS name, users can access the application using a custom domain.

## Concepts Learned

### What is DNS?

DNS (Domain Name System) translates human-readable domain names into network locations so users can access applications without remembering complex addresses.

Example:

```text
example.com
```

instead of

```text
my-alb-123456.ap-south-1.elb.amazonaws.com
```

---

### What is Route53?

Amazon Route53 is AWS's managed DNS service used to:

- Manage DNS records
- Register domains
- Route user traffic
- Integrate with AWS resources

---

### What is a Hosted Zone?

A Hosted Zone contains DNS records for a domain.

Example:

```text
example.com
```

Common records stored inside a Hosted Zone:

- A Record
- CNAME Record
- Alias Record
- MX Record
- TXT Record

---

### What is an Alias Record?

An Alias Record allows a domain name to point directly to AWS resources such as:

- Application Load Balancer
- CloudFront
- S3 Static Website
- API Gateway

Example:

```text
app.example.com
          │
          ▼
Application Load Balancer
```

---

## Key Takeaways

- Route53 is AWS's DNS service.
- Hosted Zones store DNS records.
- NS records define authoritative DNS servers.
- Alias Records can point directly to AWS resources.
- Route53 works together with ALB to provide custom domain access.
- Route53 performs DNS resolution, while ALB distributes traffic to backend EC2 instances.
