## Understanding the User Data Script

The following line was used in the user data script:

```bash
INSTANCE_ID=$(curl -s http://169.254.169.254/latest/meta-data/instance-id)
```

### Purpose

This command retrieves the unique EC2 Instance ID of the current server and stores it in a variable named `INSTANCE_ID`.

This allows the EC2 instance to display its own identity on the web page.

---

### Detailed Breakdown

#### 1. curl

```bash
curl
```

`curl` is a command-line tool used to send requests to a URL and retrieve the response.

It works similarly to how a web browser requests a web page, but it runs from the terminal.

---

#### 2. -s

```bash
curl -s
```

The `-s` option enables **silent mode**.

Without `-s`, curl displays additional progress information.

Example:

```text
% Total    % Received    % Xferd
100  19
i-0123456789abcdef
```

With `-s`:

```text
i-0123456789abcdef
```

Only the actual output is returned.

---

#### 3. EC2 Metadata Service

```bash
http://169.254.169.254
```

This is a special AWS endpoint called the **EC2 Instance Metadata Service (IMDS)**.

Every EC2 instance can access this endpoint to retrieve information about itself, such as:

- Instance ID
- Private IP Address
- Public IP Address
- Availability Zone
- AMI ID

---

#### 4. Instance ID Path

```bash
/latest/meta-data/instance-id
```

This metadata path returns the unique Instance ID of the current EC2 instance.

Example:

```text
i-0123456789abcdef
```

---

#### 5. Command Substitution

```bash
$()
```

The `$()` syntax executes a command and captures its output.

Example:

```bash
TODAY=$(date)
```

The output of the `date` command is stored in the variable.

---

#### 6. Variable Assignment

```bash
INSTANCE_ID=
```

Stores the command output inside a variable named `INSTANCE_ID`.

Example:

```bash
INSTANCE_ID=i-0123456789abcdef
```

---

### Execution Flow

```text
curl
  │
  ▼
EC2 Metadata Service
(169.254.169.254)
  │
  ▼
Returns Instance ID
(i-0123456789abcdef)
  │
  ▼
Stored in INSTANCE_ID Variable
```

---

### How It Is Used In This Project

The Instance ID is displayed on the web page using:

```bash
echo "<h1>Server Generated by ASG</h1>
<h2>$INSTANCE_ID</h2>" > /var/www/html/index.html
```

Example Output:

```text
Server Generated by ASG

i-0123456789abcdef
```

---

### Why This Is Useful

When an Application Load Balancer distributes traffic across multiple EC2 instances, refreshing the website may show different Instance IDs.

Example:

```text
Refresh 1

Server Generated by ASG
i-111111111
```

```text
Refresh 2

Server Generated by ASG
i-222222222
```
